# Niva changelog

## 1.1.0 — Current mobile release

### Delivered

- Renamed and branded the mobile app as Niva, including application icon and startup assets.
- Added the five-area app experience: Home, Timeline, Add, Records, and Profile.
- Delivered local profile, feeding, sleep, growth, vaccination, medication, and medical-document records.
- Added WHO-reference growth assessment, charts/history, medication dose tracking, and local medication reminders.
- Added camera/document import, local document management, backup/restore, and a printable/shareable pediatric health report.
- Added EAS internal Android APK and production Android App Bundle configuration.

### Notes

- The mobile version is `1.1.0`; the Android `versionCode` checked into `app.json` is `2`.
- Backup version 1 excludes profile photos and document files because they use device-local URIs.
- Native device testing is required before store distribution.
